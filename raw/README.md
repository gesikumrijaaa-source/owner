# Materiale grezzo

Qui va il materiale del corso così come viene esportato. Non si modifica mai.

Convenzione dei nomi, una sottocartella per modulo:

```
raw/
  01-nome-modulo/
    01-titolo-lezione.md      (trascrizione o testo della lezione)
    01-titolo-lezione.vtt     (sottotitoli, se esportati)
    01-titolo-lezione.pdf     (slide o dispensa)
    02-titolo-lezione.md
  02-nome-modulo/
    ...
```

Formati che Claude legge direttamente: `.md`, `.txt`, `.vtt`, `.srt`, `.pdf`, `.docx`, `.pptx`.
I video vanno trascritti prima: qui si mette la trascrizione, non il video.
